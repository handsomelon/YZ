## YZ 0.4.0

**把你的技术，变成一个能持续获客的生意。**

YZ 是原生 macOS 工作台。它每天从 GitHub Issue 和 22 个 CG 社区里捞出**真实的技术需求**，用你本机的 AI 起草一份够专业的诊断，你审一遍，去原帖亲自答。答得多了，圈子里就有你的名字——单是自己来的。

> Apple silicon · macOS 14+ · 本机运行 · 数据不上云 · **MIT 开源**
> [产品说明](https://github.com/handsomelon/YZ#readme) · [贡献指南](https://github.com/handsomelon/YZ/blob/main/CONTRIBUTING.md)

### 赚钱路径：一条漏斗，五个环节

不是「AI 自动发广告拉客」。真实路径是这样，每步标了现状：

| # | 环节 | 谁做 | 现状 |
| --- | --- | --- | --- |
| 01 | **捞需求** — 22 个渠道收进真实提问 | YZ 自动 | ✅ |
| 02 | **筛价值** — 判断值不值得答、能不能答 | 你看一眼 | ✅ |
| 03 | **备弹药** — AI 起草诊断 + 回复草稿 | YZ 自动 | ✅ 需模型网关 |
| 04 | **真人答** — 审完，你去原帖发 | 你 | ✅ 人工发布 |
| 05 | **收信任** — 私信、加好友、接单、卖服务或课程 | 你 | 🚧 渠道已登记，成交在平台侧 |

关键在 01–03 提速：原来找一道题 + 想清楚怎么答要 20 分钟，现在压到几分钟。同样一天，覆盖题量翻几倍——**传播面靠量变引起质变，不靠刷屏**。第 05 步不在 App 里发生，也不该在里面发生：技术人的信任只能用真解答换。

### 四个页面

- **问题收件箱** — 填 `owner/repo` + 关键词扫 GitHub Issue（默认 `KhronosGroup/glTF-Blender-IO` + `export, material`），自动跳过 PR，命中即入账。社区帖粘链接收进来。右侧看原帖、活动记录、草稿、审核状态。
- **来源与登录** — 22 个渠道四组：项目与技术社区 8（GitHub Issue + Blender Artists / Blender 开发者论坛 / UE Character & Animation / UE Question / Godot 五路 RSS）、国内社区与视频 5、国际视频与社区 3、商品与收款 6（Patreon / Payhip / Fab / Superhive / 微信支付 / 支付宝商家）。每源读取、匹配、错误状态都直说。
- **执行管线** — 01 进件 ✅ / 02 DSH 诊断 ✅ / 03 精神 APP·Blender 🚧 / 04 尺度 APP·视频 🚧 / 05 审核与回复 ✅。
- **模型与设置** — 网关地址 + 模型 ID + API Key 存 macOS 钥匙串；一键 `doctor` 查本机 DSH。

### AI 备到什么程度

点一条工单生成草稿，输出四块：**缺失信息**（该问提问者什么）、**最小复现建议**、**人工核验项**（未复现的结论必须标注，不许猜）、**社区回复草稿**（与提问者语言一致，改改就能发）。

第三条是提示词里最关键的：技术圈最掉信誉的事就是 AI 一本正经胡说。YZ 的设计假设是**帮你组织，不替你断言**。

### DSH 对话桥

工作台核心作为插件挂进本地 DeepSeek Harness，对话里直接操作工单账本：`yz_status`、`yz_scan`、`yz_community_scan`、`yz_list`、`yz_read`、`yz_save_draft`（存待审草稿，**不发布**）、`yz_release_status`（只读）。`watch: true` 时 DSH 开着每 15 分钟自动巡检。

> DSH 是本地 AI 框架，不是云托管平台——数据不上云，用的是你自己选的模型。

### 下载与安装

```bash
curl -LO https://github.com/handsomelon/YZ/releases/download/v0.4.0/YZ-0.4.0-macOS-arm64.zip
curl -LO https://github.com/handsomelon/YZ/releases/download/v0.4.0/YZ-0.4.0-macOS-arm64.zip.sha256
shasum -a 256 -c YZ-0.4.0-macOS-arm64.zip.sha256   # 必须看到 OK
unzip YZ-0.4.0-macOS-arm64.zip && mv YZ.app /Applications/
open /Applications/YZ.app
```

本包 SHA-256：`a69bb69b53d841a4a502ebe0c7b53ce75652a5cd4b8a8c5cb921017a608f100c`

**首次打开会被 Gatekeeper 拦一次** —— 包是 ad-hoc 签名、未公证，`spctl` 判 `rejected`。这是预期行为，不是文件损坏（先做上面的校验）。放行方式任选：

- 「系统设置 → 隐私与安全性」页面下方点 **仍要打开**；
- 或已校验过包后：`xattr -dr com.apple.quarantine /Applications/YZ.app`

**前提**：Apple silicon、macOS 14+、系统 `python3`（`xcode-select --install` 即可）；AI 草稿额外需要 `dsh 0.2.1-rc.5` 和兼容 Chat Completions 的模型网关。

每页详细操作、命令行等价命令、数据位置、从源码构建、卸载 → [完整说明](https://github.com/handsomelon/YZ/blob/main/docs/releases/v0.4.0.md)

### 它明确不做什么

这一节比功能列表重要，边界是刻意画死的：

- ❌ **不自动发帖、不自动回复、不群发私信** —— 代码里对外请求只有只读 GET（GitHub API + RSS），没有任何写接口。答案永远由你亲手发。
- ❌ **不抓登录态** —— 需要登录的站只给跳转链接。
- ❌ **不上传你的数据** —— 工单本机 SQLite，密钥系统钥匙串，模型直连你配的网关。
- ❌ **不替你下结论** —— 未复现项要求标注。
- ❌ **不承诺收入** —— 省的是找题和写作时间，能不能接到单取决于你答案的质量。

反过来：**正因为不刷屏，你的号才不会被封，你的名字才值钱。**

### 数据位置

`~/Library/Application Support/yizhi/` 下的 `tickets.sqlite3`（账本）、`github-watch.json`（值守）、`project-repo.json`（项目登记）、`runtime/`（草稿临时目录，用完即删）。API Key 在 macOS 钥匙串。bundle ID 沿用 `com.cova.yizhi`，覆盖安装不丢数据。

---

### 当前限制（v0.4.0）

1. **未公证** — 首次打开需手动放行一次。
2. **仅 Apple silicon** — `arm64` 单架构，Intel Mac 不能跑。
3. **写回未接** — 本版只读进件 + 本地审核，不做自动回复。
4. **DSH 版本钉死** — 草稿生成校验 `dsh 0.2.1-rc.5`，其他版本明确报错而非静默降级。
5. **03/04 工序未接** — 精神和尺度只有启动入口，派单链路待接。
6. **国内渠道手动** — 小红书、B站、抖音等无公开 API，靠手动收件存链接。

### 开源 · 一起做

**MIT 许可证** —— 随便用、随便改、随便分发、拿去卖都行，保留版权声明即可。

- **直接 fork 走** —— 改 bundle ID、自己发版，不用等任何人批准
- **提建议不用会写代码** —— [开 Issue](https://github.com/handsomelon/YZ/issues/new) 说「我希望它能……」
- **改代码提 PR** —— 验收就三条：能跑、不越界、说明白，见 [CONTRIBUTING.md](https://github.com/handsomelon/YZ/blob/main/CONTRIBUTING.md)

底线：任何自动发帖、自动回复、批量私信、刷量的代码不会合并。这个项目自己也是站在别人的开源工作上做的——SwiftUI、Python 标准库、Node 内置模块、DeepSeek Harness，**零第三方依赖**。

### 先免费，值了再说

**免的部分永远免费。** 全部源码、完整功能、说明书、发布包、Issue 答疑都不要钱。MIT 在法律层面锁死了这件事：今天免费给你的东西，以后任何人都收不回去。

**付费的部分是自愿支持。** 帮你接到单、省下几个下午，可以支持一下；不支持也不影响使用，功能一个不少。

> 这道理是从打游戏里学来的。当年打英雄联盟有个老师愿意花时间教我怎么玩阿木木——怎么开团、什么时候进场、什么时候该缩。他没收一分钱，那段东西我记到现在。技术是靠人传人传下去的。所以这个工具先当那个免费的老师，帮你在真实问题里把本事练出来；等你接到单赚到钱，想回来支持就支持，想回来教下一个新人就教。钱是结果，不是前提。
